- 공통 헤더는 매 요청 `cfg`·`cat` 를 R 하고, USER 세션일 때만 `crt`(줄 수 배지 — `COUNT(*)`)를 R 한다.

- 8번 결제처리는 한 트랜잭션이다. `trk` R 은 트랙 줄의 `order_item.track_snapshot` 을 채우려고 읽는다.

- 1번 `trk` R 은 메인 트랙 패키지 영역의 구성 요약. 5번은 트랙이면 구성표(`trk`), 낱개면 함께 먹지 말 것 목록(`cnf`). 6·7번 `trk`·`cnf` R 은 동시 섭취 · 중복 섭취 경고 계산.

- 38번은 조합 전체를 같은 일수로 낱개 여러 줄 담는다. 이미 있는 줄은 일수를 덮어쓴다(U). `cnf` R 은 서버 재검사 — 경고만 싣고 막지 않는다.
- 40번은 한 트랜잭션: 같은 이름이 없으면 `cmb` C, 있으면 덮어쓰기 확인 후 `cmb` U → `cmi` 전부 D → 다시 C.
