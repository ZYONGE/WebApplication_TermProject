## 4. 작업 규칙

- 설계 대상은 **입력받은 각 데이터의 저장과 사용**이다. (공지 항목 7)
  화면에서 입력된 값이 → 어느 테이블에 저장되고 → 어느 화면에서 다시 쓰이는지를 **끝까지 추적**한다.
- `docs/CRUD.md`는 화면 × 테이블 매트릭스로 유지한다. **배선 누락 검출이 본래 목적**이다.
- 테이블·컬럼 이름은 확정 후 임의 변경하지 않는다. 변경 시 PM을 거쳐 JSP·Schema 트랙에 전파한다.
- MySQL 9.6.0 기준으로 설계한다. 타 DBMS 전용 기능 사용 금지.
- ERD는 텍스트(Mermaid 또는 표)로 `docs/ERD.md`에 작성한다. 외부 작도 서비스 링크 금지. (공지 항목 10)
